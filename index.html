DEMO 1

歩行訓練プロジェクション

床面に投影される歩行ガイドと、AIによるリアルタイムのフィードバックを再現。 右側には作業療法士向けタブレットの記録が自動で溜まっていきます。

TOOL

WOZ収録ツール

Wizard of OZ方式で対話コーパスを収集するためのオペレータ卓。 応答を送るたびに、質問・応答・カテゴリの表に自動で記録されます。

対話デモ（Gemini API + 音声読み上げ）は Google Colab で実行します。 手順は rehavision/README.md を参照してください。
WOZツールは operator.html を開いたあと「ユーザ役用ディスプレイを開く」を押すと2画面構成になります。
