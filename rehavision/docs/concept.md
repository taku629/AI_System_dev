# Rehavision 企画概要

人工知能システム開発 第7班
山田 煌一郎（A）／髙原 光月（B）／小山 雄輝（C）／鶴田 大智（C）／秦 拓夢（D）／伊藤 明俐（E）

## 背景・課題

1. **人材配置の現状**: 1施設あたりの作業療法士の配置人数が過少
2. **説明業務の課題**: 専門用語による患者・家族との意思疎通の難化
3. **回復情報の把握**: 作業療法による効果が可視化されにくい

## 提案システム: Rehavision

**「AIが導き、回復を支えるスマートリハビリ環境」**

`AI for Omni-Care`（チーム医療情報支援サービス）と連携する、リハビリ特化の新機能。

### 仕組み

1. 天井カメラ・LiDARで患者の動作を計測・解析
2. プロジェクターで床や机に次の動作・手順を投影し、訓練を支援
3. 計測データをAIが分析・蓄積し、回復状況を可視化

### 構成要素

| コンポーネント | 役割 |
|---|---|
| 天井カメラ・LiDAR | 動作計測・解析 |
| プロジェクター | 床・机への訓練ガイド投影 |
| 作業療法士向けタブレット（AIアシスタント） | リハビリ記録の確認、評価結果の要約、家族への説明文作成、記録作成サポート |
| LLM (RAG) | 情報検索・要約・生成（多職種DBを横断） |
| 家族向け音声UI | 回復状況や今後の見通しをわかりやすく説明 |

### システムフロー

```
患者の訓練
  ↓
天井カメラ・LiDARで動作記録
  ↓
プロジェクターで訓練を支援
  ↓
患者情報・訓練記録を蓄積
  ↓
音声UIが家族へ状態を説明
  ↓
家族の質問を作業療法士へ共有
```

### ターゲット / 価値

| 対象 | 価値 |
|---|---|
| 患者 | 動きが分かりやすい／正しい動作をサポート／回復状況を実感できる |
| 作業療法士 | 情報検索・記録作成の効率化／説明業務の負担軽減／質の高いリハビリを提供 |
| 家族 | 回復状況を分かりやすく把握／安心してリハビリをサポート |

### 目的

**作業療法士の負担軽減とリハビリ効果の可視化**

- 患者の状態・訓練状況・過去記録のAI整理／分析
- 音声による質問への即時回答
- 情報検索・説明・記録作成業務の効率化

## デモの狙い

課題PDF「デモ」スライドで示されている通り、実機（カメラ・LiDAR・プロジェクター）を使わず、以下2つのソフトウェアデモで価値を提示する。

1. **音声質問応答デモ**（Gemini API + Prompt Template + Reference によるRAG風応答 → TTS読み上げ）
   作業療法士・家族からの質問にAIが患者記録を踏まえて回答する場面を再現。
2. **歩行訓練プロジェクションのUIシミュレーター**
   床投影による歩行訓練ガイドと、AIによるリアルタイムフィードバック（例:「左足の踏み出しが少し不安定です！」）を画面上で再現。
